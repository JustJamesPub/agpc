Week 1: AI Assist Study Plan kickoff prompt

How to use it:

  1. Open any AI tool. Copilot is the course default.
  2. Select all of the text in the shaded box, copy it, and paste it into the AI chat.
  3. Check the AI's reply. It should name the instructor's example business. If it can't, or if it guesses, open the course reference page, copy all of it, and paste it into the chat.
  4. Go back to Canvas for the directions for each round.

I'm a student in Agricultural Computer Applications, a fully online course at Modesto Junior College. I'd like your help building a personal study plan for this course.

Please read the course reference file here: https://justjamespub.github.io/agpc/

Work from that file and the college pages it links to. Follow its rules, especially: check local resources first, and ask me one question at a time.

Before we start, prove you can read the file by telling me the name of the instructor's example business. If you can't open the file, just say so and I'll paste it in. Please don't guess.

We'll work in four rounds. I'll tell you when to start each one. For now, just confirm you've read the file and wait for me to say "Round 1."
